Copy and paste these commands ONE BY ONE into your Git Bash terminal:

cd /c/Users/Harry/Downloads/ArchitectAI-Clean


STEP 2: Configure Git (first time only)
================================================================================

git config --global user.name "Harry"

(Replace "your-email@example.com" with your actual GitHub email)


STEP 3: Initialize Git repository
================================================================================

git init


STEP 4: Add GitHub remote
================================================================================

STEP 5: Add all files
================================================================================

git add .


STEP 6: Create commit
================================================================================

git commit -m "feat: Complete deployment setup with AWS Lambda + Vercel"


STEP 7: Push to GitHub
================================================================================

git branch -M main
git push -u origin main
